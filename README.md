# jon's resume

Forked from [Jake's Resume](https://github.com/jakegut/resume)

Based on law student resume format from [UVic LCO](https://law-uvic.12twenty.com/) Applications Guide

Template is free to use without attribution. 

Dependencies: 
- A TeX distribution, e.g. [TeX Live](https://www.tug.org/texlive/) or [TinyTeX](https://yihui.org/tinytex/)
- A text editor or IDE, e.g. [VSCodium](https://vscodium.com/) or [TeXStudio](https://www.texstudio.org/)
- A LaTeX compiler or extension, e.g. [LaTeX Workshop](https://github.com/James-Yu/LaTeX-Workshop) or [TeXStudio](https://www.texstudio.org/)

Alternatively, you may use an online LaTeX editor, such as [LetX](https://letx.app/) or [Overleaf](https://www.overleaf.com/) **(recommended for less technical users)**

TeX package requirements: 
- titlesec
- fullpage
- preprint
- marvosym
- enumitem
- fancyhdr
- babel
- babel-english
- txfonts
- fontaxes
